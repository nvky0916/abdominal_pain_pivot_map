# 腹痛ピボットマップ

急性腹痛の鑑別を **Pivot & Cluster** の考え方で整理する学習用ツール。

- **軸を選んでマップ**：問診でわかる軸を1〜4つ選ぶと、その場でベン図ができる。領域に触れると、その組み合わせの疾患と「次に聞くと分かれる問診」が出る。
- **疾患を中心にマップ**：疾患を1つ選ぶと、その疾患と軸を共有する疾患が周りに並ぶ。共有しない軸が、見分けるための問診になる。
- **疾患の詳しい説明**：疾患ごとの説明ページ。病態・身体所見・初期対応・ピットフォールなど、自分で書いた説明を読む。

## 軸の並び（OPQRST）

問診で聞く順に、軸を次のグループに分けている。

| グループ | 軸の例 |
|---|---|
| 年齢・性別 | 小児・若年、生殖年齢女性、男性、高齢（65歳以上） |
| **O** 発症様式 | Sudden、Acute（数分〜数時間）、Gradually、発症時の状況 |
| **P** 増悪・寛解因子 | 体動で増悪、前屈で軽快、食事で増悪 |
| **Q** 痛みの質 | のたうち回る痛み、裂けるような痛み、焼けるような痛み |
| **R** 部位・放散痛 | 心窩部〜下腹部などの部位、痛みの移動、背部・肩・鼠径への放散 |
| **S** 強さ・随伴症状 | 悪心・嘔吐、腹痛→嘔吐の順、下痢、血便、発熱 など |
| **T** 時間経過 | 2日以内の持続痛、持続痛、間欠痛、発作性、反復、数週以上 |
| 追加の問診 | 食歴、旅行歴、月経歴・妊娠の可能性 |
| 既往・生活歴 | 心房細動・動脈硬化、飲酒、糖尿病、透析・心不全、開腹歴 など |

赤い **HR** の印は High Risk な痛み（Sudden、腹痛→嘔吐の順、2日以内の持続痛）。
**High Risk Patient** は軸ではなく、ページ上部のチェック欄にある（項目は `js/data.js` の `HIGH_RISK`）。

## 疾患の説明を書く

3つ目のタブ「疾患の詳しい説明」に、疾患ごとの説明ページがある。
中身は `js/diseases/` の各疾患に `d:{...}` の形で書く。項目の種類は `js/data.js` の `DETAILS`（病態・身体所見・初期対応・コンサルト・ピットフォール）。

```js
{id:"app", l:"虫垂炎", n:"急性虫垂炎", t:2, a:[...], k:"...", x:"...",
 d:{patho:"虫垂の内腔が閉塞し…\n初期は内臓痛、のちに体性痛", pit:"高齢者・妊婦は所見が乏しい"}},
```

改行したいところには `\n` と書く。書いていない項目は、書き方のヒント付きの「未記入」の枠になる。

## 手元で開く

`index.html` をダブルクリックしてブラウザで開くだけ。インストールは不要。
`data.js` や `diseases` フォルダのファイルを書き換えて保存したら、ブラウザを再読み込みすると反映される。

## GitHub に載せて、ネットで見られるようにする

1. GitHub にログインし、右上の **＋ → New repository**。名前を `pivot-map` などにして **Create repository**。
2. 作ったリポジトリの画面で **uploading an existing file** を押し、このフォルダの中身（`index.html`・`css`・`js`・`README.md`）をまとめてドラッグして **Commit changes**。
3. **Settings → Pages** を開き、Source を **Deploy from a branch**、Branch を **main** と **/(root)** にして **Save**。
4. 1〜2分待つと `https://<ユーザー名>.github.io/pivot-map/` で開けるようになる。

### GitHub 上で直接編集する

リポジトリで `js/data.js`（軸）か `js/diseases/` の中のジャンルファイル（疾患）を開き、右上の鉛筆マーク（Edit）を押す。書き換えたら **Commit changes**。数十秒〜1分で公開ページにも反映される。
変更の履歴は **History** に残るので、いつでも前の状態に戻せる。

## 自分で軸を考える

### 軸を足す（data.js）

`AX` の中に1行足す。

```js
wt:{c:"T5",n:"体重減少",q:"この数か月で体重は減りましたか？",w:"悪性腫瘍・慢性炎症を示唆"},
```

| 項目 | 意味 |
|---|---|
| `wt` | 軸のID。英数字で、ほかと重ならない名前 |
| `c` | グループ（`BG` 年齢・性別、`O` `P` `Q` `R` `S` `T` ＝OPQRST、`AD` 追加の問診、`HX` 既往・生活歴） |
| `hr` | High Risk な痛みの軸なら `hr:1`（画面で赤い HR の印が付く）。なければ書かない |
| `n` | 画面に出す名前 |
| `q` | 患者への聞き方 |
| `w` | その答えが何を示唆するか |

### 疾患に軸を持たせる（diseases フォルダ）

疾患の `a:[...]` に軸IDを足す。これが Cluster の設定。

```js
{id:"crc", l:"大腸癌閉塞", ..., a:["eld","prog","nogas","vom","wt"], ...},
```

### 疾患を足す（diseases フォルダ）

該当するジャンルのファイルを開き、`addDiseases("…", [ ... ]);` の中に1行足す。各ファイルの冒頭に、そのジャンルの追加候補を書いてある。`t` は緊急度（1=致死的、2=緊急、3=準緊急）。

```js
{id:"intus",l:"腸重積",n:"腸重積症",t:1,a:["yng","col","vom","diar"],k:"間欠的に泣く乳幼児、イチゴゼリー状便",x:"エコー（target sign）"},
```

### ジャンルを増やす

1. `js/diseases/00_genres.js` の `GENRES` に1行足す（例：`{ id: "peds", group: "その他", n: "小児特有" }`）
2. `js/diseases/` に新しいファイルを作り、`addDiseases("peds", [ ... ]);` と書く
3. `index.html` の下のほうに `<script src="js/diseases/新しいファイル.js"></script>` を1行足す

画面上部の「表示するジャンル」で、ジャンルごとに図に出す・出さないを切り替えられる。

### 書き間違えたら

ページの上に赤い警告が出て、どの疾患のどの軸がおかしいかを教えてくれる。
よくある原因は次の3つ。

- 軸IDの綴り間違い（`"fev"` を `"fever"` と書いた、など）
- `"` や `,` の付け忘れ
- `{` と `}`、`[` と `]` の対応が崩れている

「読み込めないファイルがあります」と出たら、ファイル名や置き場所（`js/` フォルダの中か）を確認する。
ページが真っ白になったときは、文法のミスでプログラム全体が止まっている。直前に編集した行を見直す。

## 勉強の進め方の例

1. 1つの疾患を選び、`a` の軸を自分で考えて書き換える。
2. 「疾患を中心にマップ」で、似ている疾患とどの軸で分かれるかを見る。
3. 分かれないペアがあれば、それを分ける新しい軸を考えて `AX` に足す。
4. 足した軸が「次に聞くと分かれる問診」に出てくるか確かめる。

## 注意

学習用の整理図。各疾患の軸は典型像に基づく単純化で、実際の患者では欠けることも加わることもある。
