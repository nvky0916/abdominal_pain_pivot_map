# 腹痛ピボットマップ

急性腹痛の鑑別を **Pivot & Cluster** の考え方で整理する学習用ツール。

- **軸を選んでマップ**：問診でわかる軸を1〜4つ選ぶと、その場でベン図ができる。領域に触れると、その組み合わせの疾患と「次に聞くと分かれる問診」が出る。
- **疾患を中心にマップ**：疾患を1つ選ぶと、その疾患と軸を共有する疾患が周りに並ぶ。共有しない軸が、見分けるための問診になる。

## ファイルの役割

```
pivot-map/
├── index.html      ページの骨組み（タイトル・説明文）
├── css/style.css   見た目（色・文字・レイアウト）
├── js/data.js      ★ 軸と疾患のデータ。勉強で触るのはほぼここだけ
├── js/app.js       図を描く・操作に反応するプログラム
└── README.md       このファイル
```

## 手元で開く

`index.html` をダブルクリックしてブラウザで開くだけ。インストールは不要。
`data.js` を書き換えて保存したら、ブラウザを再読み込みすると反映される。

## GitHub に載せて、ネットで見られるようにする

1. GitHub にログインし、右上の **＋ → New repository**。名前を `pivot-map` などにして **Create repository**。
2. 作ったリポジトリの画面で **uploading an existing file** を押し、このフォルダの中身（`index.html`・`css`・`js`・`README.md`）をまとめてドラッグして **Commit changes**。
3. **Settings → Pages** を開き、Source を **Deploy from a branch**、Branch を **main** と **/(root)** にして **Save**。
4. 1〜2分待つと `https://<ユーザー名>.github.io/pivot-map/` で開けるようになる。

### GitHub 上で直接編集する

リポジトリで `js/data.js` を開き、右上の鉛筆マーク（Edit）を押す。書き換えたら **Commit changes**。数十秒〜1分で公開ページにも反映される。
変更の履歴は **History** に残るので、いつでも前の状態に戻せる。

## 自分で軸を考える（data.js の編集）

### 軸を足す

`AX` の中に1行足す。

```js
wt:{c:"sym",n:"体重減少",q:"この数か月で体重は減りましたか？",w:"悪性腫瘍・慢性炎症を示唆"},
```

| 項目 | 意味 |
|---|---|
| `wt` | 軸のID。英数字で、ほかと重ならない名前 |
| `c` | グループ（`onset` 発症・経過 / `sym` 随伴症状 / `pt` 年齢・性別 / `hx` 既往・生活歴） |
| `n` | 画面に出す名前 |
| `q` | 患者への聞き方 |
| `w` | その答えが何を示唆するか |

### 疾患に軸を持たせる

疾患の `a:[...]` に軸IDを足す。これが Cluster の設定。

```js
{id:"crc", l:"大腸癌閉塞", ..., a:["eld","prog","nogas","vom","wt"], ...},
```

### 疾患を足す

`DIS` の中に1行足す。`t` は緊急度（1=致死的、2=緊急、3=準緊急）。

```js
{id:"intus",l:"腸重積",n:"腸重積症",t:1,a:["yng","col","vom","diar"],k:"間欠的に泣く乳幼児、イチゴゼリー状便",x:"エコー（target sign）"},
```

### 書き間違えたら

ページの上に赤い警告が出て、どの疾患のどの軸がおかしいかを教えてくれる。
よくある原因は次の3つ。

- 軸IDの綴り間違い（`"fev"` を `"fever"` と書いた、など）
- `"` や `,` の付け忘れ
- `{` と `}`、`[` と `]` の対応が崩れている

ページが真っ白になったときは、文法のミスでプログラム全体が止まっている。直前に編集した行を見直す。

## 勉強の進め方の例

1. 1つの疾患を選び、`a` の軸を自分で考えて書き換える。
2. 「疾患を中心にマップ」で、似ている疾患とどの軸で分かれるかを見る。
3. 分かれないペアがあれば、それを分ける新しい軸を考えて `AX` に足す。
4. 足した軸が「次に聞くと分かれる問診」に出てくるか確かめる。

## 注意

学習用の整理図。各疾患の軸は典型像に基づく単純化で、実際の患者では欠けることも加わることもある。
